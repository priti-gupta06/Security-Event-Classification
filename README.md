# Security-Event-Classification
classify sample file events as normal , suspicious or potentially malicious.


## Project Overview
This project was completed as part of Task 24 of the Veda Technology Cyber Security Internship. The objective is to classify sample security events as Normal, Suspicious, or Potentially Malicious.

## Objectives
- Understand basic security event triage.
- Identify unusual and potentially malicious activities.
- Record a reason for each classification.
- Organize security event data using Excel or Google Sheets.

## Tools Used
- Microsoft Excel / Google Sheets
- GitHub for project documentation

## Methodology
1. Created a sample security event dataset.
2. Reviewed each event description.
3. Classified events using the available information.
4. Documented the reason for every classification.
5. Organized the data using spreadsheet formatting and filters.
6. Reviewed the classification summary.

## Classification Categories
- **Normal:** Expected activity without obvious warning signs.
- **Suspicious:** Unusual activity requiring further verification.
- **Potentially Malicious:** Activity with strong indicators of a possible attack or malware.

## Dataset
The dataset contains synthetic security event examples covering authentication, email security, network activity, endpoint security, and data access.

## Key Learning Outcomes
- Learned the basics of security triage.
- Practiced identifying phishing, brute-force attempts, suspicious logins, and possible malware indicators.
- Understood why every classification needs a clear reason.
- Learned that suspicious activity must be verified before concluding that an attack occurred.
